HARsha KJ — PERSONAL PORTFOLIO
==============================

FILES
-----
index.html  = the website structure and content
style.css   = dark theme, responsive layout, and visual effects
script.js   = rotating hero text, scroll reveal, and mobile menu

HOW TO OPEN
-----------
1. Extract this ZIP file to a folder on your computer.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted folder.
4. Open index.html.
5. If you have the VS Code Live Server extension, right-click index.html and choose
   "Open with Live Server". Otherwise, double-click index.html to open it in your browser.

PERSONALIZE BEFORE PUBLISHING
-----------------------------
1. Search index.html for "your.email@example.com" and replace it with your professional email.
2. Search for "replace-link" and replace each href="#" with your actual LinkedIn URL.
3. Add your latest resume PDF to this folder and name it resume.pdf. If you use another
   filename, update the resume link in index.html.
4. Review all project descriptions and make sure they accurately describe your own work.
5. CampusIQ's "Ask me about the project" link is a placeholder until you add a project
   repository or demo URL.
6. Update the skills section to reflect your actual current skill level.
7. Add screenshots of your actual projects when you have them.

PUBLISHING
----------
You can publish the static website with GitHub Pages. Before publishing, create a GitHub
repository, upload index.html, style.css, script.js and resume.pdf (if you want it public),
then enable GitHub Pages in the repository's Settings > Pages.

PRIVACY
-------
Only publish contact information and files you are comfortable sharing publicly.
